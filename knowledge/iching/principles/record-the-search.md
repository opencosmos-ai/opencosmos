# A search that found nothing is a finding, and belongs on the record with its date

**The rule.** When a source is ruled out, write down **what was searched, what was found, what blocks it, and on what date** — not just the conclusion. A bare *"not available"* is unfalsifiable, un-revisitable, and will be re-derived by the next person at full cost.

**When it fires.** Every time a wanted source is set aside, for any reason: no digitisation, wrong licence, wrong edition, technically unreachable.

---

## Why this holds

**"Unavailable" is a claim about one day's searching, and it decays.** Scans appear. Copyrights expire on a schedule. A blocker that is real in September is not necessarily real in March. A conclusion recorded without its reasoning cannot be re-examined, so it hardens into a permanent exclusion built out of a temporary fact.

**The reason matters more than the verdict, because reasons have different lifespans.** Wilhelm's German is blocked because the only transcription available is set from a 1987 edition — a *transcription* problem, which lapses the moment a scan of the 1924 printing appears. McClatchie was blocked because no digitisation could be found — an *availability* problem, which lapsed within a day. Val d'Eremao is blocked because the complete text was never digitised while a partial serialisation was — a *completeness* problem, which needs a different kind of looking. Three exclusions, three unrelated futures. Recorded as "not available" they would be one undifferentiated pile.

**And it is proof against the search being repeated badly.** The parent project records its Guodian search for exactly this reason, in a section that opens *"the search is recorded so nobody repeats it"* — having already been wrong once about a licence and having chosen to print the correction rather than quietly edit it away.

**This rule paid for itself inside a single session**, which is the strongest argument available for it. A sweep across archive.org, OpenLibrary, the Google Books API and open web search concluded that McClatchie's 1876 translation had no reachable digitisation. That conclusion was wrong, and Shalom found the volume on HathiTrust. **Because the search had been written down — naming the four places looked and what each returned — the correction was a paragraph rather than an argument**, and the record now shows both the miss and where it was found.

## Where it does not fire

**A source ruled out on grounds that cannot change does not need re-checking, only recording once.** The excavated-manuscript reconstructions are excluded because they are living scholarship; that is not a fact about today's search results.

**And this is not a licence to keep every dead end.** The rule covers sources that were *wanted* — things on the list, named in the method, worth having. A passing thought that was never a candidate is not a finding.

---

## What it obliges

1. **Name where you looked**, specifically enough that someone can look somewhere else.
2. **Name the blocker by kind** — rights, availability, completeness, format — because the kind determines what would unblock it.
3. **Date it**, and mark the section as a claim about that date rather than about the world.
4. **When a recorded search turns out wrong, print the correction next to it** rather than editing it away. The miss is part of the record.
